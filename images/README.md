# Header photo

Add the carousel photo here as `suraya.jpeg` (the header in `index.html`
references `images/suraya.jpeg`). Any reasonably-sized JPG/PNG works — the
site crops it into a circle and scales it to fit.

Until a file is added, the header shows a 🎠 placeholder instead of a
broken image.
